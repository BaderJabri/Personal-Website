Drawing a wing rib involves a lot of small steps: trace the outline, cut the spar slots, add holes, then dimension everything. I wanted to describe the part once and let Claude handle those commands inside AutoCAD.

## How it works

The plugin runs inside AutoCAD and lets Claude create and inspect drawing objects directly. It uses .NET 8 and AutoCAD's ObjectARX interface, with commands passed over a local connection. Claude checks the drawing between steps so it can catch mistakes before adding more geometry.

## A wing rib, step by step

Claude starts with the outline, adds slots for the wing's supporting beams, then cuts weight-saving holes and adds dimensions.

The layers keep the outline, cutouts, centerlines and dimensions separate, so the result is a drawing you can continue editing.
