The data is in a spreadsheet. The presentation is in Canva. Plotit connects the two: upload a CSV, get charts, and add them to the design you're already working on.

## How it works

The React app sends the file to a Python service, which cleans the data, selects columns and chart types, and renders the results with Plotly. I focused on the exchange between Canva and the service so uploading a file and getting a chart felt like one task.

In the hackathon demo, a chart took about 15 seconds to generate. The project explores a simple idea: spend less time moving data between tools and more time deciding what the chart should say.
