I — Claude × AutoCAD

A drafting agent

Claude drives AutoCAD through an MCP server, and the drawing it produces is a real one.

Plate 1
Scale 2:1
the argument

1. Thirty minutes by hand, and almost all of it is convention rather than judgement.

2. Fourteen tools, exposed over MCP: polyline, offset, rectang, circle, arraypath, dimlinear, dimdia, and the layer commands.

Drafting a wing rib1 is work that is ninety percent convention. The outline comes from a NACA table, the spar slots sit at fixed chord fractions, the lightening holes taper along the camber line. None of that requires a person, but all of it has to be right, and CAD automation has historically failed because scripting a drawing is harder than drawing one.

The agent samples the airfoil, emits a closed polyline, offsets it inboard for the web, places the cutouts, then dimensions the result2. Every action is recorded as a timestamped event, which is the only reason the replay on the frontispiece can exist — it is a recording, not a re-enactment.

What it cannot yet do is reason about tolerance. It draws nominal geometry with complete confidence, and nominal geometry is the difference between a drawing and a part.
