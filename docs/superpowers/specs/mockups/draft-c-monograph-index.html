IIIa note on method

1. Systems Design Engineering, University of Waterloo, 2022–2027.

2. A curve is fair when its curvature varies smoothly — a drafting term that turns out to describe good software too.

I build software that ends up touching something physical1 — a drawing, a position, an airframe. The work is less about the model than about whether the thing it produces survives contact with a machine shop or a market open.

Most of it starts as a line that has to close: a profile that has to be fair2, a signal that has to mean something before you can size a position against it.

I am looking for a W27 co-op where the output is measurable.
