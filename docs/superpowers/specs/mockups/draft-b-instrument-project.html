An agent that drafts real parts. Claude Code drives AutoCAD through an MCP server — polylines, offsets, arrays, dimensions — and the replay on the index is an actual run, not an animation built to look like one.

Thesis

Drafting a wing rib is thirty minutes of work that is ninety percent convention. The outline comes from a NACA table, the spar slots sit at fixed chord fractions, the lightening holes taper along the camber line. None of that needs a human, but all of it has to be correct — and CAD automation usually fails because scripting a drawing is harder than drawing it.

Mechanism

An MCP server exposes fourteen AutoCAD commands as tools. The agent samples the airfoil, emits a closed polyline, offsets it inboard for the web, places the cutouts, then dimensions the result. Every action is recorded as a timestamped event, which is what makes the replay possible at all.

Open risk

Tolerance handling. The agent draws nominal geometry confidently; it does not yet reason about fits, and that is the difference between a drawing and a part.
