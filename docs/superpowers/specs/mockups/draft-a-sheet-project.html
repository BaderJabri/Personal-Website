Claude × AutoCAD

in draft 2026 · drafting agent

An agent that drafts real parts. Claude Code drives AutoCAD through an MCP server — polylines, offsets, arrays, dimensions — and the session on sheet 1 is a replay of an actual run, not an animation drawn to look like one.

Why it exists

Drafting a wing rib is thirty minutes of work that is ninety percent convention: the outline comes from a NACA table, the spar slots go at fixed chord fractions, the lightening holes taper along the camber line. None of that needs a human, but all of it needs to be correct, and CAD automation historically fails because scripting a drawing is harder than drawing it.

How it works

An MCP server exposes fourteen AutoCAD commands as tools. The agent samples the airfoil, emits a closed polyline, offsets it inboard for the web, places the cutouts, then dimensions the result. Every action is recorded as a timestamped event, which is what makes the replay on the index sheet possible.
