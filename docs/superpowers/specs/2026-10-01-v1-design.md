## Idea

Bader's projects all turn one thing into another: prompts into parts, tiles into patterns, speech
into text, spreadsheets into charts. The headings are those transformations. Where a project can
run in the browser, the site shows a small working version of it instead of describing it.

## Pages

| Route | Content |
|---|---|
| `/` | Hero (interactive name), Claude × AutoCAD replay, live Tile To Pattern toy, live Plotit toy, Whisper4Windows, short intro |
| `/work/` | All four projects with real screenshots (the CAD project shows its part plotted to paper), plus three projects without write-ups |
| `/work/{slug}/` | Project write-up (MDX), metrics, stack, links, next project |
| `/about/` | Bio, Patterned AI experience, education, recognition, volunteering, a mate-in-one chess puzzle, tools |
| `/contact/` | Availability, email with copy, GitHub, LinkedIn, résumé |

Every page except Contact ends in a contact band; the footer carries the theme toggle.

## Interaction and motion

| Piece | Behaviour | Reduced motion |
|---|---|---|
| Dot field (whole site) | Faint 26 px dot grid on a fixed canvas. Breathes slowly; dots near the pointer swell, lean away and tint to the accent; a click sends one ripple; drifts at 0.25× scroll. ~30 fps when idle, stopped in background tabs. | One static frame |
| Name | Variable-font weight lens follows the pointer (wght 620 → 900, wdth 125 → 108); one wave on load. Letter boxes are pinned, so nothing reflows. | Static |
| Claude × AutoCAD replay | Scripted session (zod-validated JSON, real NACA 2412 geometry) plays once in view, pauses off screen, Replay button. | Finished drawing + Replay |
| Tile To Pattern toy | Edit a 4×4 Truchet tile, grid / brick / half-drop, size, colours; pattern drifts until dragged. | No drift |
| Plotit toy | Editable table and chart in sync; drag points (axis freezes while dragging), arrow keys, line / bars; line draws in. | No draw-in |
| Chess puzzle | Three hand-checked mate-in-one positions, with a stalemate trap called out. | Same |
| Reveals, counters | Sections fade up once; metrics count up once; pages fade in; covers zoom slightly on hover. | Off |

CLS measured at 0.0000 on every page at 1280 and 390 wide, with pointer sweeps and full scrolls.
